# 微信朋友圈图片导出工具

从本地手机备份中提取并下载微信朋友圈原图。支持 iPhone（iMazing / iTunes / Finder 等）未加密备份以及华为 HiSuite 备份。

> **重要**
> 本工具仅用于导出你本人合法持有的本地备份数据，不上传任何信息，也不修改原始备份文件。请勿将其用于获取他人隐私。

---

## 工作原理

微信客户端在浏览朋友圈时，会将已加载动态的元数据缓存到本地数据库中（iOS 为 `wc*_*.db`，安卓为 `SnsMicroMsg.db`），其中包括图片的 CDN 链接、访问令牌（token）以及加密图片所需的 ISAAC-64 密钥。

微信的朋友圈图片存储在独立的 CDN 服务器上，其访问权限与后续设置的朋友圈可见范围（例如“最近三天可见”或“最近一个月可见”）相互独立。本工具通过解析本地备份数据库中的缓存记录，直接向 CDN 拉取图片并在本地完成解密与重命名。

> **注意**
> 只能导出**曾经在手机上加载并缓存过**的朋友圈动态；从未浏览过的动态不会出现在本地数据库中，无法恢复。

## 平台支持与功能对比

| 维度 | iPhone（iOS） | 华为（EMUI / HarmonyOS 2–4） | 现成数据库文件 |
|---|---|---|---|
| **支持的备份来源** | iMazing（整机备份或“导出 App 数据”）、iTunes、Finder、爱思助手等 | 华为手机助手（HiSuite）备份目录 | 直接提供 `wc*_*.db` 或 `SnsMicroMsg.db` |
| **支持的形态** | 含 `Manifest.db` 的整机目录、含 `Documents/` 的 App 容器目录，或上述目录的 `.zip` / `.tar.gz` 压缩包 | 含 `info.xml` 与 `com.tencent.mm*.tar` 的备份目录 | 单个 `.db` 文件 |
| **备份加密要求** | 仅支持**未加密**备份 | 支持加密备份，需输入备份密码解密 | 需为未加密数据库 |
| **通讯录与身份识别** | 自动读取 `WCDB_Contact.sqlite`，显示 `wxid`、昵称、备注名，并区分“好友 / 非好友” | 安卓通讯录库（`EnMicroMsg.db`）已加密，**仅显示 `wxid`**，需通过“最近 20 条动态预览”确认人物 | iOS 库自动尝试关联同级通讯录；安卓库仅显示 `wxid` |
| **不支持范围** | 加密的 iOS 备份 | HarmonyOS NEXT（纯血鸿蒙） | 加密的聊天记录库 |

## 快速开始

### 方式一：使用免安装发行包（推荐）

适用于 Windows 64 位系统，无需预先安装 Python。

1. 前往 **Releases** 页面下载 `wechat-moments-exporter-v<版本号>.zip`。
2. 将压缩包解压到路径较短的目录（例如 `D:\wechat-export`），避免触及 Windows 的 260 字符路径上限。
3. 双击目录中的 **双击运行.bat** 启动工具。

> **提示**
> 发行包内嵌了未签名的便携版 Python，可能触发 Windows Defender 拦截。如遇提示，请在“Windows 安全中心 > 保护历史记录”中允许运行。

### 方式二：从源码运行

需要 Python 3.8 或更高版本。

```bash
pip install -r requirements.txt
python src/main.py
```

## 使用步骤

启动后，按终端提示完成以下 6 个步骤：

1. **选择备份类型**：选择 iPhone 备份、华为 HiSuite 备份或已有数据库文件。
2. **指定备份位置**：将备份文件夹、压缩包或 `.db` 文件直接拖入终端窗口（或粘贴完整路径）。如选择华为备份，系统会验证目录结构并提示输入备份密码。
3. **选择保存位置**：按 Enter 键使用默认目录（工具会自动选择剩余空间最大的可写磁盘），或输入自定义路径。
4. **扫描并选择目标发布者**：
   - iOS 备份可按“全部 / 只看好友 / 只看非好友”筛选列表。
   - 按编号选择要导出的发布者，支持翻页浏览。
5. **预览确认**：工具会显示该发布者最近 20 条动态的发布日期与正文摘要，便于核对身份（对仅显示 `wxid` 的华为备份尤为重要）。
6. **下载与解密**：工具自动拉取原图、执行 ISAAC-64 解密、识别真实图片格式并保存。支持断点续传与 429 限流退避，完成后可继续选择下一位发布者导出。

### 命令行单人导出

如果已有提取好的数据库文件与目标 `wxid`，可直接运行命令行脚本跳过交互流程：

```bash
python src/backup_one.py <wxid> <输出目录> <数据库路径>
```

脚本会自动识别安卓 `SnsMicroMsg.db` 与 iOS `wc*_*.db`。

## 输出文件说明

工具会为每位发布者创建独立子目录（iOS 优先使用备注名或昵称，华为使用 `wxid`），图片按以下规则命名：

```text
YYmmdd_<朋友圈正文>_<序号>.<扩展名>
```

示例：

```text
250624_今天天气真好_01.jpg
250624_今天天气真好_02.jpg
230301_无文字_01.jpg
```

**命名与时间规则**：

- **字符清洗**：Emoji 及不可显示字符替换为 `□`；Windows 非法文件名字符（`\ / : * ? " < > |`）替换为 `_`。
- **长度与空文本**：正文超过 40 个字符自动截断（当保存路径较长时会动态缩短上限）；无有效文字时记为 `无文字`。
- **同日重名**：同一天内存在清洗后正文相同的多条动态时，在正文后追加 4 位短哈希区分。
- **格式与时间**：根据文件头自动写入真实扩展名（`.jpg`、`.png`、`.webp`、`.gif`），并将文件的修改时间与创建时间（Windows）还原为该条朋友圈的发布时间。

**辅助文件**：

| 文件名 | 说明 |
|---|---|
| `_list.csv` | 该发布者的动态清单（发布时间、正文、图片数），UTF-8 BOM 编码，可直接用 Excel 打开 |
| `_manifest.json` | 已完成项记录，用于中断后的断点续传 |
| `_failures.txt` | 下载失败的条目与链接清单（仅在存在失败项时生成） |

## 已知限制与常见问题

- **华为备份为何无法显示昵称和备注？**
  安卓微信将通讯录保存在加密的 `EnMicroMsg.db` 中，解密密钥与设备信息强绑定且随版本变化，本工具暂不破解聊天与通讯录库。你可以借助第 5 步的“最近 20 条动态预览”判断每个 `wxid` 对应的联系人。
- **华为备份解密较慢且占用空间较大**
  解密过程需要通过 `kobackup-decrypt` 将加密分卷还原为 `.tar` 归档后再抽取 `SnsMicroMsg.db`，耗时与备份体积成正比，请确保输出目录所在磁盘留有充足的临时空间。
- **为什么部分图片会下载失败？**
  下载过程需要联网。部分引用自公众号图床（`mmbiz.qpic.cn`）的历史图片或已从 CDN 彻底清除的资源无法拉取，这类记录会写入 `_failures.txt`。
- **为什么不支持 HarmonyOS NEXT（纯血鸿蒙）？**
  HarmonyOS NEXT 采用了全新的备份结构与沙盒机制，不再兼容旧版 HiSuite 备份格式。
- **是否支持导出聊天记录？**
  不支持。本工具仅处理朋友圈图片缓存。

## 构建离线发行包

`build.py` 仅依赖 Python 3.8+ 标准库。运行后会自动拉取 Windows 嵌入式 Python 与 `pycryptodome` wheel，执行源码隐私泄露检查和运行时自检，并在 `dist/` 目录生成离线压缩包：

```bash
python build.py --version 1.0.0
```

如需通过代理下载构建依赖：

```bash
python build.py --version 1.0.0 --proxy http://127.0.0.1:7897
```

构建完成后终端会输出产物路径、体积与 SHA256 校验值，可直接用于发布说明。
